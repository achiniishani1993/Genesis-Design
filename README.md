# Genesis-Design
Website design using Sass
A multi-page responsive portfolio website built using HTML5, SCSS (Sass), and modern CSS layout techniques like Grid and Flexbox.

🚀 Features

* Multi-page layout (Home, Products, Contact)

* SCSS architecture with partials

* CSS Grid & Flexbox layouts

* Reusable variables and maps

* Sass folder compilation setup

* Clean and maintainable structure
